# TestX 用户使用手册

## 软件简介

TestX 是一款专业的 IoT 设备测试和语音识别桌面应用程序，主要用于物联网设备的消息测试、语音识别准确性测试以及代码模板管理。软件采用现代化的界面设计，提供了丰富的功能模块来满足不同的测试需求。

## 主要功能模块

### 1. 仪表板（Dashboard）

仪表板是软件的主界面，提供了系统概览和快速访问功能：

- **系统状态监控**：显示总日志条数、语音识别配置状态、IoT连接状态
- **配置状态检查**：实时检查语音识别和IoT平台的配置状态
- **快速导航**：提供到各功能模块的快速访问入口

### 2. 报文测试（Message Test）

报文测试模块是软件的核心功能之一，用于测试IoT设备的消息收发：

#### 2.1 新建测试

**功能路径**：报文测试 → 新建测试

**支持的测试模式**：
- **表单模式**：通过图形界面填写测试参数
- **代码模式**：使用Python代码自定义测试逻辑

**测试参数配置**：
- **主题（Topic）**：MQTT消息主题
- **QoS等级**：消息质量等级（0、1、2）
- **载荷（Payload）**：消息内容
- **产品密钥（Product Key）**：IoT平台产品标识
- **设备名称（Device Name）**：目标设备名称
- **循环测试**：支持设置循环次数和间隔时间

**使用步骤**：
1. 选择测试模式（表单或代码）
2. 填写必要的连接参数
3. 配置消息内容
4. 设置循环测试参数（可选）
5. 点击发送按钮执行测试

#### 2.2 测试记录

**功能路径**：报文测试 → 测试记录

- **记录查看**：查看所有历史测试记录
- **自动刷新**：支持5、10、15、30秒自动刷新间隔
- **操作功能**：重新发送、编辑、删除测试记录
- **数据管理**：支持批量操作和数据导出

### 3. 代码模板管理

代码模板功能帮助用户管理和复用测试代码：

#### 3.1 模板管理

**功能路径**：代码模板

- **模板创建**：支持创建Python等多种语言的代码模板
- **模板编辑**：在线代码编辑器，支持语法高亮
- **标签分类**：通过标签对模板进行分类管理
- **搜索功能**：支持按名称、描述、标签搜索模板

**使用步骤**：
1. 点击"新建模板"按钮
2. 填写模板名称和描述
3. 选择编程语言
4. 编写代码内容
5. 添加相关标签
6. 保存模板

#### 3.2 标签管理

**功能路径**：代码模板 → 标签管理

- **标签创建**：创建自定义标签
- **颜色设置**：为标签设置不同颜色
- **标签统计**：显示标签使用统计信息

### 4. 语音识别设置

语音识别模块提供了完整的语音识别配置和测试功能：

#### 4.1 配置模式

**功能路径**：设置 → 语音识别

**向导模式**：
- 按步骤引导完成语音识别配置
- 适合初次使用的用户

**高级模式**：
- 提供详细的配置选项
- 适合有经验的用户

#### 4.2 配置项目

**API配置**：
- 配置语音识别服务的API密钥
- 设置服务端点和认证信息

**识别设置**：
- 音频格式配置
- 识别语言设置
- 识别精度调整

**热词设置**：
- 添加自定义热词
- 提高特定词汇的识别准确率

**语音识别测试**：
- 实时录音测试
- 识别结果显示
- 准确率评估

### 5. IoT平台配置

**功能路径**：设置 → IoT平台配置

配置IoT平台的连接参数：
- **平台类型**：支持多种IoT平台
- **连接参数**：服务器地址、端口、协议
- **认证信息**：密钥、证书等安全配置
- **连接测试**：验证配置的正确性

### 6. 变量管理

**功能路径**：设置 → 变量管理

- **全局变量**：定义在测试中使用的全局变量
- **默认变量**：系统预定义的变量
- **自定义变量**：用户自定义的变量
- **变量引用**：在测试代码中引用变量

### 7. 其他设置

#### 7.1 外观设置
- **主题切换**：支持明暗主题切换
- **字体设置**：自定义界面字体
- **布局调整**：个性化界面布局

#### 7.2 日志管理
- **日志查看**：查看系统运行日志
- **日志级别**：设置日志记录级别
- **日志导出**：导出日志文件

#### 7.3 数据管理
- **数据备份**：备份测试数据和配置
- **数据恢复**：从备份文件恢复数据
- **数据清理**：清理过期的测试记录

## 快速开始指南

### 第一次使用

1. **启动软件**：双击TestX图标启动应用程序

2. **配置IoT平台**：
   - 进入"设置" → "IoT平台配置"
   - 填写IoT平台的连接信息
   - 测试连接确保配置正确

3. **配置语音识别**（可选）：
   - 进入"设置" → "语音识别"
   - 选择"向导模式"按步骤配置
   - 完成API配置和基本设置

4. **创建第一个测试**：
   - 进入"报文测试" → "新建测试"
   - 选择"表单模式"
   - 填写基本的测试参数
   - 点击发送执行测试

### 常用操作流程

#### 执行IoT消息测试

1. 确保IoT平台配置正确
2. 进入"报文测试" → "新建测试"
3. 填写目标设备信息
4. 配置消息内容
5. 执行测试并查看结果
6. 在"测试记录"中查看历史记录

#### 管理代码模板

1. 进入"代码模板"页面
2. 点击"新建模板"创建模板
3. 使用标签对模板分类
4. 在测试中引用模板代码

## 技术架构

### 前端技术栈
- **框架**：React + TypeScript
- **路由**：TanStack Router
- **UI组件**：Radix UI + Tailwind CSS
- **状态管理**：React Query + Zustand
- **代码编辑器**：Monaco Editor

### 后端技术栈
- **框架**：Tauri (Rust)
- **数据库**：SQLite
- **音频处理**：Rust音频库
- **IoT通信**：MQTT客户端
- **语音识别**：腾讯云语音识别API

## 开发环境搭建

### 前置要求
- Node.js 18+
- Rust 1.70+
- pnpm 8+

### 安装依赖
```bash
# 安装前端依赖
pnpm install

# 安装Tauri CLI
cargo install tauri-cli
```

### 开发模式
```bash
# 启动开发服务器
pnpm tauri dev
```

### 构建应用
```bash
# 构建生产版本
pnpm tauri build
```

## 注意事项

1. **网络连接**：确保设备能够正常访问IoT平台
2. **权限配置**：确保应用程序具有必要的网络和文件访问权限
3. **数据备份**：定期备份重要的测试数据和配置
4. **版本更新**：软件支持自动更新，建议保持最新版本

## 故障排除

### 常见问题

**连接失败**：
- 检查网络连接
- 验证IoT平台配置参数
- 确认设备认证信息

**语音识别不工作**：
- 检查麦克风权限
- 验证API配置
- 测试网络连接

**测试记录丢失**：
- 检查数据库文件
- 尝试从备份恢复
- 联系技术支持
